# CV MTB Frontend

The frontend code for the CV MTB Website. Built on React + Tailwind CSS.

Some notes on running it for development:

1. Make sure you have NPM installed. [I recommend using NVM-Windows if on Windows.](https://github.com/coreybutler/nvm-windows/releases/tag/1.2.2) If you're on Linux, you probably know what you're doing so I won't advise you there.
2. Once you've cloned this project (requires git, [see this for installation](https://git-scm.com/downloads/win)), and once you've gotten to the root directory of the project, run `npm i`
3. Once everything is installed, run `npm run start` to run a local development server.

Google/ChatGPT is your friend if you run into issues doing the above. Once the above is done, any changes you make in files should appear immediately, and should make development easier.

A few other recommendations:

- I would recommend working in a different git branch if you know how to do that, to ensure that your code is separate from the main release, and that you commit frequently to save your progress
